## Terminologia preferida

Preferências na voz de BlackSpirits. Aplicam-se ao *conceito* correspondente, não como substituição cega da palavra. Quando o original se referir a outro sentido, mantém a forma correta.

- **código aberto** quando o conceito for *open source*. Mantém **software livre** se o original se referir explicitamente ao movimento ou denominação *free software* (FSF, Stallman);
- **fixado** para conteúdo *pinned*. **afixado** continua correto para um aviso exposto num local;
- **predefinição** para *default*. **padrão** continua correto para *pattern* ou *standard*;
- **link** para hiperligação. **ligação** continua correta noutros sentidos (ligação telefónica, ligação de dados, ligação afetiva);
- **Idioma** como rótulo de interface. **idioma** em texto corrido;
- página inicial; Acerca; separador; Transferir; Carregar; Guardar; Utilizador; Ecrã.
